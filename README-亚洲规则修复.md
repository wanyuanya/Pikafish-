# SkyRule v96 亚洲规则修复

本包基于 `SkyRule-v96.zip`，修复了亚洲规则的实际调用路径、循环计数和主要特殊棋例。

## 修复内容

1. `Rule=AsianRule` 现在进入与天天规则相同的循环特征提取框架，并调用 `asian_judge_priority()`；此前虽然存在亚洲规则函数，但 `rule_judge()` 实际走的是旧版 `detect_chases()`。
2. 循环判定按“每方半循环步数”判断长将。原代码将每方的将军次数与整个循环长度比较，偶数循环下会漏判；SkyRule 与 AsianRule 均已修正。
3. 亚洲规则不再误用天天象棋的连续将军上限和“分捉放行”状态。
4. 默认关闭无条件 `SKYDBG` 输出，仅定义 `SKY_DEBUG` 时保留调试信息。
5. 亚洲模式使用比赛口径的 100 着自然限着；天天规则仍保留原可配置阈值。
6. 亚洲路径记录攻击子身份，并加入合法反吃、真根/假根、车捉炮、炮马捉车、炮台捉子、炮牵制车、同类子反吃、分捉和将帅/兵卒长捉例外。
7. 加入直接将杀威胁探测；长杀、兑、拦、献等非长捉循环按亚规作和。
8. `position.h` 提供 `Rule` 选择器的自包含兜底定义，便于覆盖到未改造的完整 Pikafish 源树。

## 测试材料

`tests/天规测试局面最新.txt` 保留了用户提供的 35 个局面，但这些是天规例子，本轮不作为亚洲规则回归依据。

完整的 35 条逐条覆盖审计见 [`docs/亚洲规则比赛规则审计.md`](docs/亚洲规则比赛规则审计.md)。

## 构建说明

本压缩包是原输入包的精简源码包，未包含完整 Pikafish 的其余源文件、Makefile、NNUE 网络和构建依赖，因此本包内无法独立编译。请将 `src/` 中的文件覆盖到对应的完整 Pikafish 源树后，再按目标平台编译；若宿主树已经定义 `Rule`，可预先定义 `SKYRULE_RULE_ENUM_DEFINED` 避免兜底枚举重复定义。

正式比赛的裁判通知次数、要求变着状态不属于引擎搜索历史；复杂多步 TTC 也需要更完整的棋例状态机，审计文件中已明确列出，不把静态引擎判定夸大为完整人工裁判。
